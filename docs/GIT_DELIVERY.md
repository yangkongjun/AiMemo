# 每次交付的 Git 同步约定

用户已指定仓库：https://github.com/yangkongjun/AiMemo.git 。2026-10-27 已确认连接具有读写权限，首次检查仓库为空且为公开仓库。

默认工作分支 `floatmemo-ai`。空仓库先在默认 `main` 建立导航 README，再从该提交建立开发分支；源码、文档及以后交付提交放在开发分支。不自动合并 main。

每次完成可交付代码或文档版本后：

1. 读取远端当前分支与相关 AGENTS/贡献规则，保留既有历史及用户修改。
2. 完成对应检查，记录结果和未测项目；更新需求状态与开发说明。
3. 逐项检查拟提交文件，排除密钥、签名、笔记和私人日志等内容。
4. 以说明本次改变的提交信息提交，通过 GitHub 连接或已授权的 Git 通道同步。
5. 读取远端分支与提交验证，给用户分支名、提交链接和简短说明。

每次聊天回复或临时生成文件不单独提交。失败时明确区分“本地完成”“已提交”“远端未成功”；不强制推送，不声称已开启后台重试或无人值守任务。

默认同步源码、资源、测试、文档和验证摘要；APK/Release、CI 及自动发布需按用户明确要求另行配置。本仓库同步不包含手机笔记同步或云备份功能。

本次为既有 V0.2.6 基线和文档的首次同步，不批准或实施审核稿中的三项新需求。原应用代码保持一致。公开手工构建脚本改为从环境变量读取签名密码，仅属发布准备，不修改应用行为。

## V0.3.0范围批准

用户已明确同意“现在可以按照之前提出的需求进行开发”。本次提交交付V0.3.0功能、测试与说明，后续同范围修正无需重复索取已经给出的授权。分支、隐私文件排除和验证远端的约定继续生效。
