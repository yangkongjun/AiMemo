## 本次结果

| 需求 | 实现 | 边界 |
| --- | --- | --- |
| 扩大生成预算 | AI设置分别配置整理/搜索max_tokens，默认8192/4096；读取等待默认120秒；每次操作使用预算快照，保留原地址和密钥 | 应用范围不是模型保证；短诊断64；不自动加量、续写或重跑已完成笔记 |
| 插入图片 | 完整编辑页系统选择、光标插入、本机原图副本、占位符编辑、块状预览、内部缩放查看，悬浮窗预览和编辑入口 | JPEG/PNG/静态WebP；不做OCR/识图/相机/粘贴；原图不上模型 |
| 媒体完整备份 | ZIP含笔记、主题、历史、纠正和原图，CRC/路径/大小/hash校验、冲突ID重映射、先文件后DB及中断恢复记录 | 旧JSON继续支持；仅JSON缺图时拒绝不完整恢复；实际Android故障注入仍未测 |
| AI搜索成本 | 当前范围先筛选、可明确查全库；候选默认10篇，总正文默认12000字符，每篇最多3窗口/1200字符，优先完整命中 | 不含向量服务；不保证无措辞重合的笔记都能召回；字符预算不是总token |
| 重复请求 | 进程级准入，一次搜索最多1次HTTP，无自动搜索重试；有效缓存最多20项/5分钟/约8MiB | 后台整理单独计数；缓存可能因版本/设置/范围/进程/淘汰失效，失败可手动重试 |
| 图片与旧AI结果 | 原文revision保留，文字指纹、任务代次与引用连续性共同检查；纯图片增删不因标记变化重复排队 | 插图切断原引用时，旧结果标记失效；未完整占位符若含附件地址，在发送前拒绝 |
| Git同步 | 本次源码、文档、测试和验证记录正常提交并验证远端；后续交付继续沿用 | 不含API Key、私钥、密码、个人笔记或SDK；APK另行交付 |

相较方案，文本Markdown渲染器保留，新增NotePreviewRenderer组合图文块；缓存另有约8MiB内存上限。为避免手工破坏占位符后泄露内部附件地址，增加发送前检查。均不增加远程调用。

## 验证与使用

105项JVM测试及APK v2/v3签名、资源结构检查通过。完整验证、证书和未测项目见[VALIDATION.md](../../floatmemo-ai-android/VALIDATION.md)。当前没有Android运行设备或真实服务凭据，不能称为真机、所有模型或恢复故障场景已验收。

1. 旧版先导出备份，再覆盖安装；不要卸载。
2. AI设置可直接修改预算，通常无需再下载APK；具体预算按服务能力调整。
3. 插图后通过预览看图；备份含图内容要选完整ZIP。
4. 搜索可换表达，但本地候选仍可能漏召回。对重要结果查看原文依据。
