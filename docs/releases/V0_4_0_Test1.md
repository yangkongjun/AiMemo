## 怎么使用

| 功能 | 入口与行为 |
| --- | --- |
| 选字工具栏 | 在完整编辑页或悬浮编辑中长按选中正文，正文上方出现横向滑动栏；左右滑动选加粗、取消粗体、普通字号、大号、特大、清除格式。保留文字选择，可继续点其他格式。 |
| 字号 | 普通为当前整张便签字号，大号为1.25倍，特大为1.5倍；整张字号继续由外观A−/A＋控制。 |
| 清单与编号 | 完整编辑页点“清单”插入 `- [ ] `，点“编号”插入递增的 `1. ` 等。选多行可一起加前缀；Enter继续列表，空项目Enter退出。 |
| 单项完成 | “编辑 / 预览”切到预览后点击项目复选框，文字划去、变淡；可再次取消。悬浮预览也可勾选。勾选项不关闭整张便签。 |
| 整张完成 | “任务/提醒”或首页待办卡片点完成；悬浮窗标题栏✓也可完成整张。便签保留、关闭悬浮窗，首页变灰，默认无查询列表与主题/标签列表完成置底。恢复待办后可重新悬浮。 |
| 状态筛选 | 首页选择全部状态、待办、已完成、普通便签。AI的“待确认/已确认”独立显示，不代表任务完成。搜索继续按相关性排序。 |
| 截止提醒 | “任务/提醒 → 设置截止时间与提醒”，设未来时间，默认提前1小时，可选15/30分钟、2小时或不提醒。已进入提前时段时，可选择立即提醒一次或仅存截止时间。 |
| 提醒权限 | Android13+请求通知权限；精确闹钟权限按系统另行授权，没有时采用可能延迟的近似提醒。关闭应用通知或该提醒频道时提示去系统设置。 |
| 批量管理 | 首页“多选当前列表”、长按卡片，或主题/标签页“多选”。勾选后移入回收站，全选只作用于当前列表范围。改变筛选会清除选择。 |
| 回收站 | 首页“更多 → 回收站”，多选恢复或确认永久删除。恢复保留原文、图片、格式、任务状态；永久删除同时清除相应整理历史和纠正记录。 |

完成或移入回收站会取消提醒，旧代次的通知动作不会作用于新状态。系统重启、升级、改时间和授予精确权限后重新安排有效提醒；截止已过不在重排时补发，截止前错过提前时点的未发提醒可尽快发送一次。正在等待的近似闹钟仍可能因系统延迟在截止后才到达。强行停止应用、设备关机、厂商省电及系统后台限制可能阻止或延迟通知，需要在实际手机核验。

回收站恢复保留提醒配置，截止前未发出的提醒重新安排；导入备份中的新便签则关闭提醒，保留截止时间，避免批量恢复后突然通知，需用户手动重设。没有联网提醒、重复周期或跨设备同步。

## 数据与边界

加粗、字号、勾选和任务状态为独立元数据，不重写原文，不因这些操作单独重跑AI。插入/修改清单和编号仍是正文修改，遵守原有AI整理规则。删除中的AI结果由活动状态和任务代次拦截；回收站不参与搜索、关联或后台整理。

完整ZIP包含原图、局部样式、勾选、任务状态和回收站。JSON包含元数据但不含原图，不能替代ZIP。文字/Markdown导出与文字分享保留原始正文，不携带本版局部样式和独立勾选状态。此前原文中的 `**加粗**` 等Markdown继续预览，工具栏“清除格式”只清除本版元数据，不移除Markdown字符。

这次是基础局部格式与清单，未实现通用富文本编辑器、任意字体/颜色、Markdown双向转换、拖动项目排序、周期提醒或云同步。此前知识分类、语义检索和逻辑关联等未完成目标继续保留在[需求状态](../../floatmemo-ai-android/REQUIREMENT_STATUS.md)，没有因本次测试取消。

## 手机测试顺序

1. 先完整备份，覆盖安装；核对旧笔记、图片、主题标签、AI设置和悬浮位置是否保留。
2. 选中一段含中文/表情的文字，滑动工具栏设粗体和大号；退出重进、预览、重启应用，检查样式及原文。完整页和悬浮编辑各试一次，确认横向滑动不丢选择。
3. 插入三项清单及三行编号，测试Enter继续、空项退出、单项勾选取消；勾选后修改该项目文字会清除其独立完成状态，避免旧任务状态误套新内容。
4. 标记整张完成，检查其悬浮窗消失、首页变灰/置底、完成筛选可见，AI确认状态独立；恢复待办后重新打开悬浮窗。
5. 设几分钟后的截止时间，选择立即提醒；测试通知允许/拒绝、精确权限允许/拒绝、屏幕关闭、应用退后台，通知中“标记完成”。再测完成/删除后不再提醒、重启后的未来提醒。
6. 在有主题/标签/搜索筛选的列表多选两条，核对仅这些便签入回收站；恢复含图笔记，确认内容与状态；用专门测试便签试永久删除。
7. 导出完整ZIP，再导入核对格式、清单、完成状态、图片与回收站；确认新导入记录有截止日期但提醒关闭。保留本次备份，不用旧版应用读取。
