# V0.3.2 标签与主题下的笔记卡片

日期2026-10-29，版本0.3.2-ai-preview、versionCode 11。用户反馈点击标签后笔记缺少区分、样式不美观。原先使用仅显示标题的系统弹窗，现在进入独立的卡片列表页，便于在打开详情之前识别内容。

## 最终行为

- 每篇笔记为白色圆角卡片，配细边框、16dp内边距与12dp卡片间距；按下时显示淡绿背景。
- 展示标题（最多两行）、本地原文预览（最多三行）、标签（最多两行）、主题、更新时间及图片数量。长文字省略，不加载图片原文件或调用AI；AI旧结果不作为预览来源。
- 顶部显示标签/主题名称、当前数量与排序说明。主题下笔记也使用同一样式，点整张卡片进入原有AI详情页。
- 标签按完整标签值匹配，主题按原始值匹配；未分类为空值，不把名为“未分类”的实际主题与空值混成一组。
- 使用原生ListView按需复用可见卡片，不一次创建全部卡片。返回上一级使用正常Activity栈；列表自身按首条可见笔记的ID及偏移尝试恢复位置，已移出列表的锚点回到顶部。
- 笔记变化后重新读取本地数据，数量和归属更新；没有匹配笔记时显示空列表说明。状态恢复逻辑已实现，但真机旋转及返回效果未实测。

## 修改入口

- `floatmemo-ai-android/app/src/main/java/io/github/floatmemo/android/BrowseActivity.java`：主题/标签入口传kind与value。
- `floatmemo-ai-android/app/src/main/java/io/github/floatmemo/android/NoteListActivity.java`：筛选、列表、卡片样式、预览与位置恢复。调整`Row`里的圆角、边框、字号、行数与间距即可改样式。
- `floatmemo-ai-android/app/src/main/AndroidManifest.xml`：新页面注册为不可外部启动。
- `floatmemo-ai-android/app/build.gradle`：提高版本号，沿用包名和签名。

本次不变更笔记存储、图片文件、AI整理/检索、模型配置或调用预算。原有“待确认”界面沿用原样，本次只改主题/标签下的笔记列表。
