# FloatMemo AI 安卓开发手册（V0.2.6）

先双击FloatMemo_Developer_Guide_Android_V0_2_6.html阅读；也提供Markdown版，方便在编辑器中修改。

本包是手册与可选的本地签名配置示例，不是新版本APK，不包含源码工程或私钥。无需重装手机应用即可阅读。源码继续使用此前的项目归档。

第一次先做“改首页一句话”的练习。已有设置优先在应用里改。可选Gradle签名示例只有在你按手册准备原私钥和本地属性后才使用；不会自动运行或改动原工程。未在你的Windows环境实测。

文件：
- FloatMemo_Developer_Guide_Android_V0_2_6.html：离线浏览版。
- FloatMemo_Developer_Guide_Android_V0_2_6.md：可编辑文档。
- examples/app.build.gradle.local-signing.example：可选的完整app/build.gradle示例。
- examples/signing.properties.example：需要用户填写的签名参数模板。

签名文件必须继续使用原维护包提供的文件。手机笔记需另行在应用内导出备份。
