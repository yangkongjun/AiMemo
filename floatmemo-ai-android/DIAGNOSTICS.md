# 如何获取本次接口诊断

1. 更新前通过“更多 → 导出全部便签（JSON）”另存当前笔记，再直接覆盖安装0.2.6，不卸载。
2. 在“AI 设置”保存地址、模型和API Key并启用。未保存的输入不会用于测试。
3. 打开“更多 → 诊断记录”，点击“测试当前已保存的配置”，等待结果。测试不发送笔记，只发送一条固定短消息；会计入次数且服务商可能收费。
4. 如果连接测试成功，但整理失败，再对一条笔记点“重新整理”，等待失败后刷新诊断记录。
5. 点击“导出”保存TXT，或点击“复制”。检查错误响应中是否有不想分享的业务内容，再提供用于排查。

## 如何阅读

记录中的“阶段”说明失败发生的位置；“错误类型”提供判断线索，不等同于已经证明某个组件有故障。HTTP状态为-1表示没有取得有效状态码。网络的系统互联网验证状态不能单独证明模型接口可达。

| 错误类型 | 已取得的信息 | 需要检查 |
| --- | --- | --- |
| LOCAL_CONFIG / KEY_MISSING / CONFIG_CHANGED | 请求未完成本机配置检查，或设置在请求期间变化 | 是否保存并启用，HTTPS地址、密钥读取、是否中途暂停 |
| LOCAL_QUOTA | 本机次数检查未通过 | 每日次数上限及本地计数保存 |
| DNS | 域名未能解析 | 地址拼写、网络、DNS |
| TLS | HTTPS证书或握手失败 | 手机时间、证书链、代理 |
| CONNECT / TIMEOUT / NETWORK_IO | 连接或读写阶段失败 | 结合阶段检查网络、端口、代理或服务速度 |
| HTTP_401 / HTTP_403 | 服务已返回拒绝访问 | Key、模型权限、服务地址 |
| HTTP_404 / HTTP_405 | 服务返回未找到或不接受POST | 接口地址、模型是否存在、请求方法 |
| HTTP_400 / HTTP_422 | 服务拒绝请求参数 | 服务响应中的参数、模型兼容性说明 |
| HTTP_429 | 服务限流或额度限制 | 服务商额度及限流规则 |
| HTTP_5xx | 服务端或网关返回错误 | 服务响应、服务状态；不代表手机必然无问题 |
| HTTP_3xx | 地址要求跳转，软件未自动跟随 | 所填地址；软件不会替换为其他路径 |
| NOT_JSON | HTTP成功但返回内容不是JSON对象 | 是否网页、网关信息或其他协议 |
| SERVICE_ERROR | HTTP成功但JSON含error | 脱敏服务响应中的code/message |
| MISSING_CHOICES / EMPTY_CHOICES / INVALID_CHOICE / MISSING_CONTENT | 服务回答信封不符合预期格式 | 顶层格式、是否返回其他API协议 |
| OUTPUT_TRUNCATED | 正式操作已收到响应，但生成达到本次输出限制 | 比较本次输出上限、completion_tokens与finish_reason；可先缩短笔记 |
| TEST_OUTPUT_LIMIT（提示类型） | 短连接测试已收到有效推理响应，但生成达到测试的64 token上限 | 接口已响应，尚未验证完整回答；继续测试一条短笔记 |
| AI_CONTENT_INVALID | 回答信封可读取，但笔记结构或来源校验失败 | 模型是否遵循要求、原文引用；连接测试不验证这些 |

## 保存范围

最近30次请求完成后记录到本机，采用原子写入。不包含请求正文和请求头，正常回答正文不记日志。失败响应最多4000字符，屏蔽当前Key、常见凭据字段以及常见正文和引用字段；未知格式仍可能带有服务商业务信息，分享前请检查。不会自动上传，也不纳入笔记JSON导出。可以单独清空诊断，笔记及AI设置不受影响。正在进行的请求完成后会产生新记录。

本版不包含系统崩溃日志或其他应用日志。更新前的No value for choices等错误没有原始响应，无法补记，需要更新后重现一次。诊断测试成功不代表后续每次请求都成功。

## 连接测试与实际整理的区别

短测试上限64 token，正式笔记整理/查找上限3000 token，二者分别记录。若短测试返回有效choices和message且finish_reason为length，即使可见正文为空，也只证明接口有推理响应，不说明笔记结果可用。日志会显示“接口连通，测试输出达上限”，不再误导用户更换模型。正式操作仍拒绝截断结果。对于WELCOME响应、鉴权错误、缺少choices等异常，测试继续报告对应问题。
