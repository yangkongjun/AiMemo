# 对需求文档的实现情况

对应 FloatMemo AI 需求 V1.0。状态表示实现范围，不表示真机验收或模型效果已达标。

| 编号 | 本版范围 | 状态 |
|---|---|---|
| FR01 | 原文先本地保存，AI 独立后台执行；保存异常可在首页查看 | 已实现，设备故障待测 |
| FR02 | 原文版本、AI文字指纹及历史来源与派生结果分开；可查看摘录，无完整历史浏览页 | 部分 |
| FR03 | 要点、例子、已有建议、背景疑问及长文逐段整理 | 已实现，效果待测 |
| FR04 | 提示词约束感受与解释；没有语义正确性的自动保证 | 部分 |
| FR05 | 对摘录做存在性校验；未做全部主题覆盖检测 | 部分 |
| FR06 | 平面主题与原文件夹 | 部分，层次待实现 |
| FR07 | 基本标签去重及已有主题复用 | 部分，同义词与合并待实现 |
| FR08 | 按主题标签浏览与单笔记修改 | 部分，结构管理待实现 |
| FR09 | 本地相似内容候选 | 部分，关系类型与双侧证据待实现 |
| FR10 | 相似候选、拒绝并保留；不自动删改原文 | 部分，重复提示待实现 |
| FR11 | 本地文字搜索、范围/预算/命中片段与有限候选AI检索 | 部分，不是全库语义索引 |
| FR12 | 命中片段、原因及定位原文 | 已实现，交互待测 |
| FR13 | 来源校验与失败降级；语义相关性须实测 | 部分 |
| FR14 | 单笔记要点回顾与浏览 | 已实现，不含 P1 专题总结 |
| FR15 | 待确认、逐条纠正和撤销 | 部分，尚无多种批处理规则 |
| FR16 | 本笔记人工锁定与纠正历史 | 部分，不含跨主题规则 |
| FR17 | 排队、重试、恢复和错误说明 | 已实现，后台设备行为待测 |
| FR18 | 版本与锁定检查、删除后不接收结果、任务代次与文字指纹、进程级搜索准入和缓存隔离 | 已实现，系统中断场景待测 |
| FR19 | 原 JSON 迁移、旧数据保留、主分类锁定 | 已实现，覆盖安装迁移待测 |
| FR20 | 完整ZIP含原图、旧JSON、预览数量、冲突副本及重复导入/缺图修复 | 已实现，完整设备恢复待测 |
| FR21 | 删除笔记及其本地历史纠正，动态关联不再展示 | 部分，没有一键清空所有数据页面 |

未开展：30条真实笔记与30条真实查询的质量评估、80%前五项找回率、人工修改比例、真机大规模性能及任何模型费用评估。文档中的这些指标不能写成当前软件已达到的效果。

## V0.3.0新增需求

已接入分别可配置的生成上限、读取等待、候选数量及搜索正文预算；图文编辑/预览/本机副本；完整媒体备份与恢复记录；同一片段原文引用；单次搜索请求及有效缓存。源码和纯逻辑测试见VALIDATION.md。

仍未实现：图片OCR/AI识图、所见即所得富文本、相机/剪贴板粘图、向量索引、全库语义召回保证、云同步。设备交互、覆盖升级、低内存与真实服务兼容性仍待实测。
